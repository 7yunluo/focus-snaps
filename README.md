# FocusSnapS

Wayland（niri / wlroots 系）下的截图与标注工具：一次抓屏后在每个显示器上铺一层浮层，框选、标注、保存或复制。

## 功能

- **多显示器**：每个显示器一个独立浮层，各自的分辨率、缩放与旋转互不干扰
- **窗口选择**：悬停高亮整块窗口，单击选中；想自由框选就直接拖动，两种方式共存
- **分数缩放与旋转**：按输出实际像素换算，选区按物理分辨率导出，浮层所见即所得
- **选区**：8 个手柄缩放、内部拖动移动、方向键微调、`Ctrl+A` 全选当前屏
- **工具条**：框选完成后出现，抓住 `⠿` 把手可移动到顺手的位置，位置按屏记住
- **标注**：画笔、高亮、直线、箭头、矩形、椭圆、文字、序号、马赛克、裁剪；24 色调色板、线宽调节、撤销 / 重做
- **文字**：就地输入——文字、光标、虚线框直接出现在落点上，所见即所得，用系统界面字体；打字时滚轮可实时调字号，回车后虚线框能直接拖动改位置
- **跟随系统主题色**：选框、手柄、工具条高亮、调色板标记都用系统强调色，改主题色即时生效
- **默认完成动作是复制**，要落盘用 `Ctrl+S` 或工具条的「保存」

## 安装

```bash
# Arch / pacman（在项目根目录）
./packaging/build-pkg.sh          # 打 tarball + makepkg -si，需要 sudo

# 或者只装到 ~/.local/bin
cargo install --path . --root ~/.local --force
```

装 `/usr/bin/FocusSnapS` 和桌面入口。依赖 `gtk4`、`gtk4-layer-shell`、`libnotify`；`wl-clipboard`（复制更可靠）与 `niri`（窗口选择）可选。

## 用法

```
FocusSnapS                     打开浮层（所有显示器）
FocusSnapS -o DP-2             只在指定显示器打开
FocusSnapS --cursor            抓屏时带上鼠标指针

FocusSnapS grab -o DP-2 [--png 路径]
                                 抓一帧；不给 --png 时输出 8 字节头（宽、高，u32 小端）+ BGRA 到 stdout
FocusSnapS full [-o 显示器] [--png 路径]
                                 不打开浮层，直接整屏保存
FocusSnapS list                列出显示器模式、旋转、逻辑尺寸与缩放
FocusSnapS detect -o DP-2      试跑窗口识别并把结果打出来（排障用）
```

### 浮层快捷键

| 按键 | 作用 |
| --- | --- |
| 单击窗口 | 选中整块窗口 |
| 拖动 | 自由框选区域 / 在选区内画标注 |
| 回车、空格、双击选区 | 复制到剪贴板（默认） |
| `Ctrl+S`、工具条「保存」 | 保存到图片目录 |
| `Ctrl+C` | 复制到剪贴板 |
| `Esc` | 退出 |
| `Ctrl+A` | 选中整块屏幕 |
| `Ctrl+Z` / `Ctrl+Shift+Z` | 撤销 / 重做 |
| 方向键 / `Shift`+方向键 | 微调选区 1px / 10px |
| 文字输入时滚轮 | 调整文字大小 |
| `Delete` | 清空选区与标注 |
| 右键 | 有选区时清空，无选区时退出 |
| `V B H L A R E T N M` | 选择、画笔、高亮、直线、箭头、矩形、椭圆、文字、序号、马赛克 |

工具按钮悬停可以看到名称与快捷键；调色板点工具条上的颜色圆点展开。

## 保存位置

默认 `$XDG_PICTURES_DIR/Screenshots`（未设置则为 `~/Pictures/Screenshots`），文件名 `年-月-日_时-分-秒.png`，重名自动加序号。用 `FOCUSSNAPS_DIR` 覆盖。

## 已知限制

- 选区限定在一个显示器内（跨屏框选不支持），保存的也是选区所在的那块屏
- 重新框选会重置标注（标注属于那一次选区）
- 需要合成器支持 `zwlr_screencopy_manager_v1` 与 `zwlr_layer_shell_v1`
- 文字输入依赖输入法，浮层需持有键盘焦点；`-o` 只开单屏时，指针要在该屏上（或该屏是焦点屏）快捷键才生效
- 多屏同时开浮层时，键盘快捷键作用于指针所在的那一块屏
- 分数缩放的输出上，浮层边缘可能有几个逻辑像素压不到；导出的截图不受影响
